# nyssance/shadcn

Source of [`@nyssance/shadcn`](packages/shadcn): the shadcn/ui registry, generated by the shadcn CLI, published as
one package.

```sh
bun run sync       # regenerate packages/shadcn/src from upstream (CLI version and styles at the top of scripts/sync.ts)
bun run typecheck
bun run build
bun run test
```

Registry sources are never edited by hand and are excluded from formatting and linting. To follow upstream, bump
the CLI version in `scripts/sync.ts`, run `bun run sync`, review the diff, and release.

Releases: the version follows the shadcn CLI that generated the sources (`bun run sync` sets it when the CLI is
newer); repackaging the same CLI release bumps the patch. Push tag `v<version>`; CI publishes with npm trusted
publishing.
